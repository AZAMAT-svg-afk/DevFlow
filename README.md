# DevFlow 🚀

DevFlow — консольный менеджер задач, написанный на Python.

## Возможности

- Создание задач
- Просмотр задач
- Поиск задач
- Изменение задач
- Удаление задач
- Сохранение задач в JSON
- Обработка ошибок пользовательского ввода

## Технологии

- Python
- JSON
- Git
- GitHub

```bash
python main.py
